# Канцеляризмы и чем их заменить. Читает crates/pr-core/src/clarity.rs.
#
# Строка: «шаблон = замена». Замена — короткая подсказка, её показывают рядом с находкой.
# Регистр и «ё» не важны: «В целях» и «в целях», «объём» и «объем» совпадают.
#
# [слова] — одно слово по начальной форме: «осуществлять» найдёт и «осуществляется».
# [обороты] — слова подряд как написаны, без знаков препинания между ними. Так
#   записаны обороты с предлогами: по начальным формам «в целях» совпало бы с «в цель».
# [обороты по начальным формам] — слова подряд по начальным формам: «денежный средство»
#   найдёт «денежных средств» и «денежными средствами».
#
# Перед тем как добавить слово, проверьте, не встречается ли оно в простых текстах:
# cargo run -p pr-core --features clarity --example clarity_stats -- <каталог textsbygrade>
# покажет, какие канцеляризмы чаще всего находятся на каждом уровне.
